HOW THE ACCESS SYSTEM WORKS
================================================================

1. USER SIGNS UP:
   - Goes to login.html, clicks "Sign Up"
   - Enters name, email, password
   - Firebase Auth creates the account
   - A Firestore document is created in "users" collection:
     {
       email: "user@email.com",
       name: "User Name",
       role: "member",          (or "admin" if email matches ADMIN_EMAIL)
       tools: [],               (empty for members, all tools for admin)
       status: "pending",       (or "active" for admin)
       createdAt: timestamp
     }
   - Member sees "Account created! Wait for admin."
   - Admin is redirected to dashboard immediately

2. ADMIN ACTIVATES USER:
   - Admin goes to Admin Panel
   - Sees pending user in the table
   - Clicks "Activate" -> status changes to "active", tools set to ALL
   - Or can selectively toggle individual tools on/off

3. USER LOGS IN:
   - Dashboard checks Firestore for user's status and tools array
   - If status is "blocked" -> signed out with error message
   - If status is "active" -> shows only tools listed in their tools array
   - If status is "pending" -> shows empty state (no tools assigned)

4. ADMIN REVOKES ACCESS:
   - Admin clicks "Block" -> status set to "blocked", tools cleared
   - User is immediately locked out on next page load
   - Admin can "Unblock" later to restore access

   git checkout index

   git push origin index

4. Wait 1-2 minutes for GitHub Pages to update
5. Admin automatically gets access (auto-sync in dashboard.html)
6. For existing members: go to Admin Panel and toggle the new tool ON

   user to read/write. For production, tighten the rules to
   only allow admin to modify other users' documents.

   Only Firestore Database is used. You can ignore Realtime Database.

5. Node.js is NOT installed on this PC. All deployments are done
   via git push. Firebase CLI was not used.

TROUBLESHOOTING
================================================================

Problem: Page keeps loading/refreshing
Fix: Press Ctrl+Shift+R to hard refresh, or clear browser cache

Problem: "Error loading dashboard"
Fix: Check Firestore rules in Firebase Console are set correctly

Problem: New tool not showing for admin
Fix: Hard refresh (Ctrl+Shift+R), auto-sync adds new tools for admin

Problem: Can't push to GitHub
Fix: Make sure you're on "index" branch: git checkout index

Problem: Firebase errors
Fix: Check Firebase Console that Auth and Firestore are both enabled
